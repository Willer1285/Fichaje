# Assets - Recursos de la Aplicación

## Logo de la Aplicación

Para personalizar el logo de la aplicación, coloca tu imagen en esta carpeta con el nombre `logo.png`.

### Especificaciones del Logo:

- **Nombre del archivo**: `logo.png`
- **Formato**: PNG (preferiblemente con fondo transparente)
- **Dimensiones recomendadas**: 200x200 píxeles
- **Relación de aspecto**: 1:1 (cuadrado)
- **Tamaño máximo de archivo**: 500 KB

### Instrucciones:

1. Prepara tu imagen con las especificaciones anteriores
2. Guarda la imagen como `logo.png` en esta carpeta (`assets/logo.png`)
3. Reinicia la aplicación para ver el cambio

Si no hay un archivo `logo.png`, la aplicación mostrará el logo predeterminado.

### Formatos soportados:

- PNG (recomendado para transparencia)
- JPG/JPEG
- BMP
- GIF
